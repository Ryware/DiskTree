# Headroom Privacy Policy

Effective date: September 30, 2026

Headroom is a local macOS disk space analyzer published by Ryware.

## Data collection

Headroom does not collect, transmit, sell, or share personal data. The app has no analytics, advertising, account system, tracking SDK, or cloud service.

## File access

Headroom accesses only folders that you explicitly select through the macOS folder picker. The App Store version uses Apple’s App Sandbox and security-scoped bookmarks to preserve access to recently selected folders. Bookmark data remains on your Mac in the app’s local preferences.

File names, paths, sizes, categories, and scan results are processed on your Mac and are not transmitted to Ryware or any third party.

## Deletion

Headroom deletes files only after an action you initiate and confirm. Trash mode asks macOS to move selected items to Trash. Permanent deletion cannot be undone.

## Network access

Headroom does not request network access and does not send scan information over the internet.

## Changes

If Headroom’s data practices change, this policy and the App Store privacy disclosure will be updated before the changed version is released.

## Contact

For privacy questions, open an issue in the [Headroom repository](https://github.com/Ryware/Headroom/issues). Do not include private file names, paths, or other sensitive information in a public issue.

## The website

The landing page at ryware.github.io/Headroom uses Google Analytics (GA4, IP anonymization on) to count page views, downloads and which demos get used. This applies to the website only. The Headroom app contains no analytics and makes no network requests.
